# Street Survival ammunition

Six original Blender models based on the generated ammo reference: single rounded pistol cartridge, three-round SMG cluster, bottleneck rifle cartridge, long sniper cartridge, three linked LMG rounds and olive rocket with charcoal nose, orange band and four fins. Five separate bullet-only GLBs provide flying projectiles without their cartridge cases.

GLB units are metres, Y up; inventory models have a ground-centred origin. Bullet-only exports are centred and point along +Y. Rocket flight uses a centred wrapper. All GLBs embed UV-mapped finish textures and PBR materials. Icons are 512 × 512 RGBA Blender renders with genuine transparent backgrounds and no ground effects. Shared cached runtime models are cloned without duplicating geometry/textures. Each export is below 5,000 triangles.

The download ZIP includes editable .blend files, texture finishes, GLBs, icons, preview and original reference. Rebuild from repository root with `pnpm assets:ammo`.
