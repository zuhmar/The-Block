# Street Survival sound effects

37 original deterministic synthesized effects, generated by `packages/art-tools/build-sounds.py`. No third-party recordings or libraries are used in the audio itself. These original project assets can be used and modified with the game.

WAV format: 24,000 Hz, mono, 16-bit PCM. The complete bank is under 600 KB. Files have short boundary fades and normalized peaks below 0.8 to leave mixer headroom. Runtime playback uses one gesture-unlocked Web Audio context, cached decoded buffers, stereo panning/distance filtering, volume and mute persistence, a master compressor and a 24-voice cap. These are stylized synthesized effects, not recordings of real firearms.

The bank covers five firearms, rocket launch, grenade throw, C4 placement/detonation, explosions, three reload phases, equip/dry fire, melee/hit feedback, player damage, pavement/grass footsteps, jumping/landing, chopping/mining, resource depletion, construction materials, dismantling, doors, pickups, loot and inventory UI.
