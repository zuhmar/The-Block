# Reference-guided Blender buildings

Five fresh buildings and 30 standalone prop models, guided by the saved sheets in `../references`. No earlier building geometry is imported. The Blender source packs all five reference images. Prop silhouettes and depth are interpreted from the concept artwork.

Run `pnpm assets:blender-buildings` at the repository root. The layout exporter reads the current building dimensions, door openings, fixture footprints and bedroom partitions from the existing game. The Blender builder creates rounded meshes and materials from a factory-empty scene, exports five game GLBs to `apps/client/src/fps/models/buildings`, exports 30 independent props to `props`, and saves exterior/interior renders and `building-library.blend` here. `report.json` records reference hashes, triangle counts, draw batches and sizes.

The source gallery has each building and its reusable prop collection arranged separately. Runtime models are exported at their local origin before arranging that gallery. All props are geometry without painted ground patches or baked terrain effects. Existing furnished rooms use the current fixture footprints. The standalone collection includes additional prop variants for later placement; it does not add arbitrary collision obstacles to the town.

Exterior styling follows the reference palettes: ochre/green store, turquoise Haven, terracotta workshop, lavender/plum residence, and blue-gray warehouse. The game's single centered pedestrian door and established opening dimensions are retained. The warehouse's decorative loading shutter is on a side wall rather than replacing the existing pedestrian doorway. Roof and ceiling meshes can be hidden together to inspect interiors. Shop, shelter and industrial doors have actual glazed openings. Individual meshes are batched by material and shell/roof/glass/door/interior role to limit draw calls.

The client preloads these assets with a loading screen and retains the previous visual factory as a fallback for failed assets. Existing door angles drive the new hinge groups. Furniture meshes use the established distance/frustum culling. Separate low-detail, non-rendered shooting proxies follow the existing building/fixture layout and moving doors; combat raycasts do not traverse the detailed artwork. Player movement collision, construction restrictions, building footprints, inventory, wood, saved structures and networking are unchanged.
