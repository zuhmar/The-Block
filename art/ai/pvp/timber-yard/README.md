# PvP timber yard concept

Original glossy cartoon environment reference for the first PvP gathering area. The user selected capture of a central point as the area-control mechanic, then requested the timber yard image first.

The concept proposes an urban timber yard approximately 32 × 32 metres, with a central capture terminal and flag, staggered log cradles and plank stacks for cover, a shipping container, an open-front saw shed, a forklift, a rear harvestable tree strip, and three distinct entrances. Leave an open apron around the capture point and clear flanking routes.

This is the visual design reference, not an implemented game area. The current 3D game is single-player; shared PvP capture ownership will require the 3D multiplayer connection. Existing harvesting, world geometry, housing plots and player data have not changed. Individual model references and game assets should be based on this artwork when building this area.
